# Contributing Guide

Thank you for your interest in Jarvis-ClawLink.

At this stage, the project is distributed in binary form only.
Source code contributions are not open.

We welcome:

- Bug reports
- Feature suggestions
- UI/UX feedback
- Documentation improvements

Please open an issue to share your feedback.

--------

感谢您对 Jarvis-ClawLink 的关注。

当前项目仅提供二进制版本，暂未开放源码贡献。

我们欢迎：

- Bug 反馈
- 功能建议
- UI/交互优化建议
- 文档改进建议

欢迎通过 Issue 提交反馈。
